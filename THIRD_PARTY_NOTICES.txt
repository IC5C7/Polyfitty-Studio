AMD ROCm / HIP SDK components (optional Windows portable build)
---------------------------------------------------------------
- The optional Windows HIP bridge is compiled from this project's source using the AMD HIP SDK headers and a Visual Studio C++ toolchain.
- HIPRTC and AMD COMGR DLLs, their required SDK DLL dependencies, device bitcode/runtime data and available SDK license/EULA notices are collected from the installed AMD HIP SDK when the HIP build option is enabled.
- The AMD driver-provided HIP runtime (`amdhip64*.dll`) is intentionally not redistributed in the application bundle. The target PC must have a compatible AMD graphics driver and a Radeon GPU supported by the relevant Windows HIP SDK release.
- AMD HIP SDK documentation and license terms: https://rocm.docs.amd.com/projects/install-on-windows/en/latest/
- Review the license/EULA/redistribution terms supplied with the exact SDK version used to build the bridge before distributing the resulting executable. The project does not grant additional rights to AMD SDK components.
